# Contacts List

A small React phonebook for adding, searching, and removing contacts. Contacts are stored in the current page's state and are not persisted after a refresh.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deploy to GitHub Pages

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds the app and deploys it to GitHub Pages whenever changes are pushed to `main`.

In the repository's **Settings → Pages**, set the build and deployment source to **GitHub Actions**. The site will be available at:

`https://BwaseFabbians0417-sudo.github.io/react-app/`
